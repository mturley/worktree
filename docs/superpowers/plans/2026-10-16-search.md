# Search Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A search bar that live-filters the home page (worktrees, Activity, Resources) and the worktree page (its resources and activity), with a typeahead dropdown of top matches.

**Architecture:** Worktree and resource matching are pure TypeScript over data the pages already load (`lib/search.ts`). Event matching runs on the server: `q` on both timeline endpoints, SQL `LIKE` for the global timeline and a Go matcher for the in-memory worktree timeline, both sharing `internal/webui/search.go`, which also returns a `match` (field + snippet) per event. The query lives in the URL (`?q=`); a `SearchContext` lets titles highlight terms without prop plumbing. The home page gets a new header holding the logo, search, global toggles and Settings.

**Tech Stack:** Go 1.22+ (`net/http`, `modernc.org/sqlite`), React + Mantine 7 + TanStack Query + wouter, Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-16-search-design.md`

## Global Constraints

- Matching is case-insensitive; whitespace splits the query into terms; **every term must match** somewhere on the item. No phrases/operators.
- An all-whitespace query is no query: no filtering, no `q` sent, no highlights.
- `q` combines (AND) with every existing filter: `archived`, `unread_only`, `resource_types`, `event_types`, `before`, `limit`, `resource_type`/`resource_id`.
- SQL `LIKE` terms are escaped for `\`, `%`, `_` with `ESCAPE '\'`.
- Snippets: about 60 runes total around the hit (30 before the hit, 30 after its end), whitespace collapsed, cut at word boundaries, `…` marks each cut. Identical rule in Go and TS.
- Worktrees match through their resources (`MATCH_WORKTREES_VIA_RESOURCES = true`, one switch in `lib/search.ts`), never through events. Resources never match through events.
- `?q=` is written with history **replace**, never push.
- Search bar debounce for the server: 250 ms. Browser-side filtering is immediate.
- Esc anywhere clears an active query unless a modal/menu/popover/listbox is open or focus is in another editable element. `/` focuses the bar when focus is not editable.
- Home header only on the home page. Worktree page: search bar right after "Open in editor".
- The dropdown (`SearchSuggestions`) must be removable by deleting it and its mount in `SearchBar`.
- Repo rules: `git add` specific files only; commits use `--signoff` and end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Don't disable lint rules.

## Review Focus

1. Query containing `%`, `_` or `\` (e.g. `ci_failed`, `100%`) — must match literally, not as wildcards. → Task 1 + Task 2 tests.
2. A term that only matches the event's resource (custom name / cached Jira summary), not the event text — the event must still be returned, with `match.field = "resource"`. → Task 2 + Task 3 tests.
3. Typing on the worktree page while a resource is selected that doesn't match — the selection must survive. → Task 11 test.
4. Pressing Esc inside an open modal or the Slack composer while a query is active — the query must stay. → Task 8 tests.
5. Clearing the query restores the exact unfiltered state (no `q` param left, timeline query key back to its no-query form so it's a cache hit). → Task 6 + Task 10 tests.

```go
package webui

import (
	"strings"
	"unicode"
)

// Search over the activity feeds (`q` on /api/timeline and
// /api/worktree-timeline). The rules mirror ui/src/lib/search.ts:
// case-insensitive, whitespace-separated terms, every term must match
// somewhere on the event. See docs/web-ui-architecture.md "Search".

// searchMatch says why an event matched, for the UI's dimmed "why" line.
// Field is "title", "body", "author" or "resource"; Snippet is text around
// the hit (body), the author, or the resource's short key (resource).
type searchMatch struct {
	Field   string `json:"field"`
	Snippet string `json:"snippet"`
}

func parseSearchTerms(q string) []string {
	var out []string
	seen := map[string]bool{}
	for _, f := range strings.Fields(strings.ToLower(q)) {
		if !seen[f] {
			seen[f] = true
			out = append(out, f)
		}
	}
	return out
}

var likeEscaper = strings.NewReplacer(`\`, `\\`, `_`, `\_`, `%`, `\%`)

func likeContains(term string) string { return "%" + likeEscaper.Replace(term) + "%" }

// searchArgsPerTerm is how many placeholders one term's group uses.
const searchArgsPerTerm = 7

// searchSQL narrows the global timeline to events matching every term. The
// resource fields are EXISTS subqueries rather than joins, so they can never
// multiply rows. Cached titles live under "title" (PR, Slack, link) or
// "summary" (Jira) in state_json — see enrichResourceDTO.
//
// SQLite's LIKE folds ASCII case only; matchEvent (Go, Unicode) decorates
// whatever SQL returns, so a non-ASCII mismatch can only make SQL stricter.
func searchSQL(terms []string) (string, []any) {
	if len(terms) == 0 {
		return "", nil
	}
	const group = `AND (
    e.title LIKE ? ESCAPE '\' OR COALESCE(e.body,'') LIKE ? ESCAPE '\' OR COALESCE(e.author,'') LIKE ? ESCAPE '\'
 OR er.resource_id LIKE ? ESCAPE '\'
 OR EXISTS (SELECT 1 FROM watcher_resource_meta m
             WHERE m.resource_type = er.resource_type AND m.resource_id = er.resource_id
               AND COALESCE(m.custom_name,'') LIKE ? ESCAPE '\')
 OR EXISTS (SELECT 1 FROM watcher_resource_state rs
             WHERE rs.resource_type = er.resource_type AND rs.resource_id = er.resource_id
               AND (COALESCE(json_extract(rs.state_json,'$.title'),'') LIKE ? ESCAPE '\'
                 OR COALESCE(json_extract(rs.state_json,'$.summary'),'') LIKE ? ESCAPE '\'))
) `
	var b strings.Builder
	args := make([]any, 0, len(terms)*searchArgsPerTerm)
	for _, t := range terms {
		b.WriteString(group)
		p := likeContains(t)
		for i := 0; i < searchArgsPerTerm; i++ {
			args = append(args, p)
		}
	}
	return b.String(), args
}

// matchEvent is the Go twin of searchSQL over an enriched event. It returns
// nil unless every term appears in some field; otherwise the highest-priority
// field containing any term.
func matchEvent(te *TimelineEvent, terms []string) *searchMatch {
	if len(terms) == 0 {
		return nil
	}
	resourceText := te.ResourceID
	if d := te.Resource; d != nil {
		resourceText = strings.Join([]string{d.ID, d.CustomName, d.Title}, "\n")
	}
	fields := []struct{ name, text string }{
		{"title", te.Title}, {"body", te.Body}, {"author", te.Author}, {"resource", resourceText},
	}
	lower := make([]string, len(fields))
	for i, f := range fields {
		lower[i] = strings.ToLower(f.text)
	}
	for _, t := range terms {
		hit := false
		for _, l := range lower {
			if strings.Contains(l, t) {
				hit = true
				break
			}
		}
		if !hit {
			return nil
		}
	}
	for i, f := range fields {
		for _, t := range terms {
			if !strings.Contains(lower[i], t) {
				continue
			}
			switch f.name {
			case "body":
				return &searchMatch{Field: "body", Snippet: snippet(f.text, t)}
			case "resource":
				return &searchMatch{Field: "resource", Snippet: te.ResourceID}
			default:
				return &searchMatch{Field: f.name, Snippet: f.text}
			}
		}
	}
	return nil
}

// snippetRadius is how many runes of context to keep on each side of a hit.
const snippetRadius = 30

// snippet returns text around the first occurrence of term (lowercase):
// whitespace collapsed, cut at word boundaries, "…" marking each cut. "" when
// term does not occur. Same rule as ui/src/lib/search.ts snippet().
func snippet(text, term string) string {
	flat := []rune(strings.Join(strings.Fields(text), " "))
	low := make([]rune, len(flat))
	for i, r := range flat {
		low[i] = unicode.ToLower(r)
	}
	tr := []rune(term)
	at := -1
	for i := 0; i+len(tr) <= len(low); i++ {
		if string(low[i:i+len(tr)]) == term {
			at = i
			break
		}
	}
	if at < 0 {
		return ""
	}
	start, end := at-snippetRadius, at+len(tr)+snippetRadius
	cutStart, cutEnd := start > 0, end < len(flat)
	if !cutStart {
		start = 0
	} else {
		// Drop the partial word at the cut.
		for start < at && flat[start-1] != ' ' {
			start++
		}
	}
	if !cutEnd {
		end = len(flat)
	} else {
		for end > at+len(tr) && flat[end] != ' ' {
			end--
		}
	}
	out := strings.TrimSpace(string(flat[start:end]))
	if cutStart {
		out = "…" + out
	}
	if cutEnd {
		out += "…"
	}
	return out
}
```

```go
func AllNonBlank(conn *sql.DB) (map[string]string, error) {
	rows, err := conn.Query(`SELECT path, notes FROM worktree_notes`)
	if err != nil {
		return nil, err
	}
	defer rows.Close()
	out := make(map[string]string)
	for rows.Next() {

		if err := rows.Scan(&path, &text); err != nil {
			return nil, err
		}
		if strings.TrimSpace(text) != "" {

		}
	}
	return out, rows.Err()
}
```

```ts
import type { ResourceDTO, WorktreeSummary } from "../api/types"
import { shortResourceRef } from "./resourceRef"

/**
 * Search: pure matching for worktrees and resources, which the pages filter
 * in the browser. Events are matched on the server (`q` on the timeline
 * endpoints, internal/webui/search.go) with the same rules: case-insensitive
 * whitespace-separated terms, every term must match somewhere.
 */

/**
 * Whether a worktree matches through its resources' fields. The one switch
 * for that behaviour, kept because it may prove too broad in use.
 */
export const MATCH_WORKTREES_VIA_RESOURCES = true

export interface SearchMatch {
  /** Which field matched, e.g. "title", "assignee", "notes", "resource". */
  field: string
  /** Text to show for it: the field's value or a snippet around the hit. */
  snippet: string
  /** For a worktree matched through a resource: that resource's short key. */
  viaKey?: string
}

/** Fields already visible as the item's title; no "why" line for them. */
export const VISIBLE_FIELDS: ReadonlySet<string> = new Set(["title", "name", "key", "branch"])

export function parseQuery(q: string): string[] {
  return [...new Set(q.toLowerCase().split(/\s+/).filter(Boolean))]
}

const SNIPPET_RADIUS = 30

/** Same rule as snippet() in internal/webui/search.go. */
export function snippet(text: string, term: string): string {
  const flat = [...text.split(/\s+/).filter(Boolean).join(" ")]
  const low = flat.map((c) => c.toLowerCase())
  const tr = [...term]
  let at = -1
  for (let i = 0; i + tr.length <= low.length; i++) {
    if (low.slice(i, i + tr.length).join("") === term) { at = i; break }
  }
  if (at < 0) return ""
  let start = at - SNIPPET_RADIUS
  let end = at + tr.length + SNIPPET_RADIUS
  const cutStart = start > 0
  const cutEnd = end < flat.length
  if (!cutStart) start = 0
  else while (start < at && flat[start - 1] !== " ") start++
  if (!cutEnd) end = flat.length
  else while (end > at + tr.length && flat[end] !== " ") end--
  let out = flat.slice(start, end).join("").trim()
  if (cutStart) out = "…" + out
  if (cutEnd) out += "…"
  return out
}

export function resourceLabel(r: ResourceDTO): string {
  return r.custom_name || r.title || r.id
}

type Field = { name: string; text: string; long?: boolean }

function resourceFields(r: ResourceDTO): Field[] {
  return [
    { name: "key", text: `${r.id}\n${shortResourceRef(r.type, r.id)}\n${r.channel_name ?? ""}` },
    { name: "name", text: r.custom_name ?? "" },
    { name: "title", text: r.title ?? "" },
    { name: "description", text: r.custom_description ?? "", long: true },
    { name: "assignee", text: r.assignee ?? "" },
    { name: "author", text: r.author ?? "" },
    { name: "reporter", text: r.reporter ?? "" },
    { name: "status", text: r.status ?? r.state ?? "" },
    { name: "labels", text: (r.labels ?? []).join(", ") },
    { name: "description", text: r.description ?? "", long: true },
    { name: "url", text: r.type === "link" ? r.url : "" },
  ]
}

function allTermsHit(lowerTexts: string[], terms: string[]): boolean {
  return terms.every((t) => lowerTexts.some((l) => l.includes(t)))
}

/** The highest-priority field containing any term, as a match. */
function firstHit(fields: Field[], terms: string[]): SearchMatch | null {
  for (const f of fields) {
    const low = f.text.toLowerCase()
    const t = terms.find((term) => low.includes(term))
    if (t === undefined) continue
    return { field: f.name, snippet: f.long ? snippet(f.text, t) : f.text }
  }
  return null
}

export function matchResource(r: ResourceDTO, terms: string[]): SearchMatch | null {
  if (terms.length === 0) return null
  const fields = resourceFields(r)
  if (!allTermsHit(fields.map((f) => f.text.toLowerCase()), terms)) return null
  return firstHit(fields, terms)
}

export function matchWorktree(
  w: WorktreeSummary,
  workspaceTitles: string[],
  resources: ResourceDTO[],
  terms: string[],
): SearchMatch | null {
  if (terms.length === 0) return null
  const own: Field[] = [
    { name: "branch", text: w.branch },
    { name: "repo", text: w.repo },
    { name: "path", text: w.path },
    ...workspaceTitles.map((t) => ({ name: "workspace", text: t })),
    { name: "notes", text: w.notes_search ?? "", long: true },
  ]
  const via = MATCH_WORKTREES_VIA_RESOURCES ? resources : []
  const texts = [
    ...own.map((f) => f.text.toLowerCase()),
    ...via.flatMap((r) => resourceFields(r).map((f) => f.text.toLowerCase())),
  ]
  if (!allTermsHit(texts, terms)) return null
  const hit = firstHit(own, terms)
  if (hit) return hit
  for (const r of via) {
    if (firstHit(resourceFields(r), terms)) {
      return { field: "resource", snippet: resourceLabel(r), viaKey: shortResourceRef(r.type, r.id) }
    }
  }
  return null
}

/** 1 label starts with the first term, 2 contains any term, 3 otherwise. */
export function rankText(label: string, terms: string[]): number {
  const low = label.toLowerCase()
  if (terms.length > 0 && low.startsWith(terms[0])) return 1
  if (terms.some((t) => low.includes(t))) return 2
  return 3
}

/** rankText, with 0 for a term that IS the resource's key or short ref. */
export function rankResource(r: ResourceDTO, terms: string[]): number {
  const keys = [r.id.toLowerCase(), shortResourceRef(r.type, r.id).toLowerCase()]
  if (terms.some((t) => keys.includes(t))) return 0
  return rankText(resourceLabel(r), terms)
}

function escapeRegExp(s: string): string {
  return s.replace(/[.*+?^${}()|[\]\\]/g, "\\$&")
}

export function splitHighlight(text: string, terms: string[]): { text: string; hit: boolean }[] {
  if (terms.length === 0 || !text) return [{ text, hit: false }]
  const re = new RegExp(`(${terms.map(escapeRegExp).join("|")})`, "gi")
  return text.split(re).filter((p) => p !== "").map((p) => ({
    text: p, hit: terms.includes(p.toLowerCase()),
  }))
}
```

```ts
import { useCallback, useMemo } from "react"
import { useLocation, useSearch } from "wouter"
import { useDebouncedValue } from "@mantine/hooks"
import { parseQuery } from "../lib/search"

const PARAM = "q"

/** How long typing must pause before the server is asked. */
export const SEARCH_DEBOUNCE_MS = 250

/**
 * The page's search query, kept in the URL as `?q=` so Back and reload keep
 * it. Written with replace: typing must not leave one history entry per
 * keystroke. Other params (`resource`, `tab`) are preserved.
 *
 * `terms` is for browser-side filtering and highlighting, immediately;
 * `debouncedQ` (trimmed) is for server requests.
 */
export function useSearchQuery() {
  const search = useSearch()
  const [location, navigate] = useLocation()
  const q = new URLSearchParams(search).get(PARAM) ?? ""
  const setQ = useCallback(
    (next: string) => {
      const params = new URLSearchParams(search)
      if (next) params.set(PARAM, next)
      else params.delete(PARAM)
      const qs = params.toString()
      navigate(qs ? `${location}?${qs}` : location, { replace: true })
    },
    [search, location, navigate],
  )
  const terms = useMemo(() => parseQuery(q), [q])
  const [debouncedQ] = useDebouncedValue(terms.length ? q.trim() : "", SEARCH_DEBOUNCE_MS)
  return { q, setQ, terms, debouncedQ }
}
```

Note: when the query is cleared, `debouncedQ` lags 250 ms; that's acceptable (the feed returns to the cached unfiltered page).

```tsx
import { useEffect, useRef } from "react"
import { CloseButton, TextInput } from "@mantine/core"
import { IconSearch } from "@tabler/icons-react"

export interface Suggestion {
  key: string
  /** Group heading: "Worktrees", "Resources" or "Activity". */
  group: string
  label: string
  detail?: string
  onPick: () => void
}

function isEditable(el: Element | null): boolean {
  if (!el) return false
  const tag = el.tagName
  return tag === "INPUT" || tag === "TEXTAREA" || tag === "SELECT" || (el as HTMLElement).isContentEditable
}

/**
 * Whether an Esc belongs to something other than the search: an open
 * modal, menu or listbox (except our own dropdown), or typing in another
 * field (the Slack composer, the notes editor). Those keep their own Esc.
 */
function escOwnedElsewhere(input: HTMLInputElement | null): boolean {
  const own = input?.closest("[data-search-root]")
  const open = document.querySelectorAll('[role="dialog"], [role="menu"], [role="listbox"]')
  for (const el of open) if (!own || !own.contains(el)) return true
  const active = document.activeElement
  return isEditable(active) && active !== input
}

export function SearchBar({
  value,
  onChange,
  placeholder = "Search worktrees, resources, activity…",
  suggestions,
}: {
  value: string
  onChange: (q: string) => void
  placeholder?: string
  suggestions?: Suggestion[]
}) {
  const ref = useRef<HTMLInputElement>(null)

  useEffect(() => {
    const onKey = (e: KeyboardEvent) => {
      if (e.defaultPrevented) return
      if (e.key === "/" && !isEditable(document.activeElement) && !e.metaKey && !e.ctrlKey) {
        e.preventDefault()
        ref.current?.focus()
        return
      }
      if (e.key === "Escape" && value && document.activeElement !== ref.current && !escOwnedElsewhere(ref.current)) {
        onChange("")
      }
    }
    document.addEventListener("keydown", onKey)
    return () => document.removeEventListener("keydown", onKey)
  }, [value, onChange])

  const onInputKey = (e: React.KeyboardEvent<HTMLInputElement>) => {
    if (e.key !== "Escape") return
    e.preventDefault()
    if (value) onChange("")
    else ref.current?.blur()
  }

  void suggestions // wired in Task 9
  return (
    <div data-search-root style={{ flex: "1 1 240px", minWidth: 0, maxWidth: 520 }}>
      <TextInput
        ref={ref}
        type="search"
        role="searchbox"
        aria-label="Search"
        size="xs"
        placeholder={placeholder}
        value={value}
        onChange={(e) => onChange(e.currentTarget.value)}
        onKeyDown={onInputKey}
        leftSection={<IconSearch size={14} />}
        rightSection={value ? <CloseButton size="xs" aria-label="Clear search" onClick={() => onChange("")} /> : null}
      />
    </div>
  )
}
```

Note: React's synthetic `onKeyDown` on the input runs before the document listener sees the native event, and `preventDefault` there makes the global handler skip it (`defaultPrevented`).

```ts
import type { ResourceDTO, TimelineEvent, WorktreeSummary } from "../../api/types"
import { matchResource, matchWorktree, rankResource, rankText, resourceLabel } from "../../lib/search"
import { shortResourceRef } from "../../lib/resourceRef"
import type { Suggestion } from "./SearchBar"

export const SUGGESTION_LIMITS = { worktrees: 3, resources: 5, events: 3 } as const

/**
 * The dropdown's rows: the top few matches per kind, ranked (exact key,
 * then title prefix, then title contains, then other fields; ties keep the
 * input order). Events arrive already matched and newest first — they are
 * the head of the page's own search-filtered feed.
 */
export function buildSuggestions(input: {
  terms: string[]
  worktrees?: { w: WorktreeSummary; workspaceTitles: string[]; resources: ResourceDTO[] }[]
  resources: { r: ResourceDTO; worktreePath?: string }[]
  events: TimelineEvent[]
  go: {
    worktree: (path: string) => void
    resource: (r: ResourceDTO, path?: string) => void
    event: (e: TimelineEvent) => void
  }
}): Suggestion[] {
  const { terms, go } = input
  if (terms.length === 0) return []
  const byRank = <T,>(xs: T[], rank: (x: T) => number) =>
    xs.map((x, i) => ({ x, i, k: rank(x) })).sort((a, b) => a.k - b.k || a.i - b.i).map((e) => e.x)

  const wts = byRank(
    (input.worktrees ?? []).filter(({ w, workspaceTitles, resources }) => matchWorktree(w, workspaceTitles, resources, terms)),
    ({ w }) => rankText(w.branch, terms),
  ).slice(0, SUGGESTION_LIMITS.worktrees)
  const rs = byRank(input.resources.filter(({ r }) => matchResource(r, terms)), ({ r }) => rankResource(r, terms))
    .slice(0, SUGGESTION_LIMITS.resources)
  const evs = input.events.slice(0, SUGGESTION_LIMITS.events)

  return [
    ...wts.map(({ w }): Suggestion => ({
      key: `wt:${w.path}`, group: "Worktrees", label: w.branch, detail: w.repo, onPick: () => go.worktree(w.path),
    })),
    ...rs.map(({ r, worktreePath }): Suggestion => ({
      key: `res:${r.type}:${r.id}`, group: "Resources", label: resourceLabel(r), detail: shortResourceRef(r.type, r.id),
      onPick: () => go.resource(r, worktreePath),
    })),
    ...evs.map((e): Suggestion => ({
      key: `ev:${e.id}`, group: "Activity", label: e.title, detail: e.match?.snippet ?? e.author,
      onPick: () => go.event(e),
    })),
  ]
}
```
